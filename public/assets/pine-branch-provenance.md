# Pine branch

Original black-on-white longleaf pine engraving generated with the built-in Image Gen tool on 2026-09-21. Prompt: a standalone fine botanical engraving with three airy long-needle clusters and a pendant pine cone, landscape 5:4, black ink on pure white, no labels or typography. Art direction follows the approved Home 2 mockup.

Source preserved at `planning/mockups/pine-engraving-source.png`. Vectorized from that raster using threshold contour tracing and 1px contour simplification. The SVG is actual traced artwork, not a manually drawn approximation and contains no embedded raster. Transparent background, cream #e5dfc8 fill, viewBox 0 0 1000 800. One coherent `pine-branch` group can be transformed for subtle whole-branch sway. Splitting needle clusters would introduce seams and is deferred.

133,382 bytes uncompressed; 49,747 bytes gzip. This exceeds the initial approximately 40KB motion brief target by about 10KB while retaining fine needle details. No external font, image, script, or network dependency. Generated art does not document a specific Aiken location.
